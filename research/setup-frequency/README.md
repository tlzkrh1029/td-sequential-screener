# TD Setup 9 빈도 측정 (WMA 0.3 스크리너의 종가 데이터)

TD Sequential 스크리너의 타당성을 검토하기 위해, WMA 0.3 스크리너([`tlzkrh1029/wma0.3-screenshot`](https://github.com/tlzkrh1029/wma0.3-screenshot))가 수집한 일봉 종가로 시간프레임별 Setup 9 빈도와 봉 수를 측정했습니다. TD Setup은 종가만으로 계산하므로 이 데이터로 정확하게 셀 수 있습니다. 카운트다운 13은 시가·고가·저가가 필요하므로 이번 측정에는 포함하지 않았습니다.

- 스크립트: [`setup_scan.py`](setup_scan.py) (Python 3, 표준 라이브러리만 사용)
- 측정일: 2026-11-01 (WMA 저장소의 2026-10-31 수집분)

## 계산 방법

- **대상:** `data/tickers.json`에서 USD 티커(`CRYPTO:xxxUSD`)가 있는 563개 종목입니다.
- **봉 분할:** WMA 엔진(`dashboard/engine.js`)의 `keyFn()`을 그대로 옮겼습니다. nD 봉은 매년 1월 1일에, 2W·3W 봉은 그해 첫 월요일에, nM 봉은 매년 1월에 다시 시작하고, 1W 봉은 월요일에 시작합니다. 구간 안에 TradingView 봉이 하루라도 있어야 그 구간을 봉으로 셉니다.
- **Setup:** TD Research v6([`kidze_td_research_v6.pine`](https://github.com/tlzkrh1029/pinescript/blob/main/td-research-v6/kidze_td_research_v6.pine) 310~314행)의 계산을 그대로 옮겼습니다. 새 Setup은 엄격한 가격 반전(price flip)에서만 시작하며, 실제 연속 카운트(raw)가 9가 된 봉을 Setup 9로 셉니다.
- **마감 봉만 사용:** 일일 수집 데이터에는 아직 진행 중인 당일 봉이 들어 있으므로 데이터의 마지막 날을 제외합니다. 각 시간프레임의 마지막 봉도 그 구간이 아직 끝나지 않았으면 제외합니다.

## 실행 방법

WMA 저장소를 받은 뒤, 그 저장소의 `data/daily` 폴더와 `data/tickers.json`을 인수로 넘깁니다.

```bash
git clone --depth 1 https://github.com/tlzkrh1029/wma0.3-screenshot /tmp/wma
```

```bash
python3 research/setup-frequency/setup_scan.py /tmp/wma/data/daily /tmp/wma/data/tickers.json
```

```bash
python3 research/setup-frequency/setup_scan.py /tmp/wma/data/daily --golden
```

- `--last YYYY-MM-DD`: 마지막 마감일을 직접 정합니다. 기본값은 데이터의 마지막 날의 전날입니다.
- `--window N`: 빈도를 세는 기간(일)입니다. 기본값은 365입니다.
- `--golden`: 위 검증 표의 BTC 확인만 실행합니다.
